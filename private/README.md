# private/

Put **your own** Halo 3 files here. Everything in this directory except this
README is git-ignored and must never be committed.

Expected layout:

```
private/
├── default.xex          # from the root of your disc dump
├── default.xexp         # optional: title update patch (see docs/DUMPING.md)
├── default_patched.xex  # generated by XenonRecomp when a .xexp is present
└── game/                # the rest of the disc contents (maps/, etc.)
```
